# Charllz IQ

A React + Vite starter website for Charllz IQ, an educational platform for Nigerian secondary school students.

## Requirements
- Node.js LTS (supported by the installed Vite version)
- npm
- VS Code or another code editor

## Run locally
1. Extract this project folder.
2. Open a terminal inside `charllz-iq`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (usually http://localhost:5173).

## Current status
This is the first frontend prototype. Navigation, feature cards and calls to action currently show demo notices. There is no real login, database, CBT engine, AI connection or teacher account yet. Those will be added in later stages.

## Brand
Navy blue, royal blue, gold and light neutral backgrounds. The interface is responsive for phones, tablets and desktops.
